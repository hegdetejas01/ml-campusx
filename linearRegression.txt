### Simple Linear Regression ###
    # One input column and one output column
    # For almost linear data
    # Fits a straight line through data: y=mx+b


    ## Coding - simpleLinearRegression.py 
        # y = mx + b
        # package = m * cgpa + b

        1. m is the weightage - how much the package is dependant on cgpa
            * if m is more, then package is more dependent on cgpa
            * if m is less, then package is less dependant on cgpa

        2. b 
            if b=0,
            then package = m * cgpa
            when cgpa is 0, then package is also 0, this is immpractical

            b is called as offset value, even if cgpa is zero(b != 0), then y has some value (b)

    ## Finding value of m and b
        1. Closed form solution: expression that can be expressed through finite number of standard operations. Formula based.
        * Ordinary least sqare (OLS)
        * for less number of features/dimensions 
        * scikit learn uses this feature

        2. Non closed form solution: uses approximation techniques
        * Gradient descent
        * uses differntiation and integration
        * it helps for higher dimensional data
        * sgd regressor used this method

    ## OLS
        * b = ybar - (m*xbar)
        * m = sum((xi-xbar)(yi-ybar))/sum((xi-xbar)^2)

        where, 
            xbar = mean value of x
            ybar = mean value of y
            xi = current value of x 
            yi = current value of y 

    ## Mathematical Derivation
        error_function (J) = sum(i=1 till n) d(i)^2

        error at a point = yi - yihat

        therefore, 
            error_function J = sum(i=1 till n) (yi - yihat)^2

        m and b decides the values of yihat
        find m and b such that, it should reduce the error

            error_function: J(m,b) = sum(i=1 till n) (yi - m*xi - b)^2

    ## m and b to minimise error_function
        * b is 0
            -> J(m) = sum(i=1 till n) (yi - m*xi)^2
            -> line can just rotate through center (b=0)
            -> changing values of m, changes the value of error and creates a curve
        
        * m is 1
            -> J(b) = sum(i=1 till n) (yi - xi - b)^2
            -> Line can just be shifted and can't rotate or change the angle
            -> changing values of b, changes the value of error and creates a curve

        * for certain values of m and b, errors are high and for certain values of m and b, errors are minimum 

        * at minimum slope = 0
        * slope means derivative

        * dJ/dm = 0 and dJ/dm = 0, through this we can find the value of m and b

        * 
            dJ/db = ybar - m*xbar - b = 0
            b = ybar - (m*xbar) # final equation
        
        * 
            J = sum(i=1 till n) (yi - m*xi - b)^2
            J = sum(i=1 till n) (yi - m*xi - ybar + m*xbar)^2 # substituting b 
            dJ/dm = -2 (yi - m*xi - ybar + m*xbar) (-xi + xbar) = 0

            m = sum((xi-xbar)(yi-ybar))/sum((xi-xbar)^2) # final equation  


    ## Regression methods - To check the efficiency of the Regression algorithm
        1. Mean Absolute error
        2. Mean square error
        3. Root mean square error
        4. R2 score - co efficient of determination
        5. Adjusted R2 score

    ## Mean Absolute Error
        * | yi - yihat |  = this is the absolute error at point i
        * MAE = (1/n) sum(i=1 to n) (| yi - yihat |)

        * Advantages:
            1. Unit of the output and MAE are the same and hence easy to compare
            2. Robust to outliers
        
        * Disavantages: Modulus function graph is not differential at point 0 - hence mean squared error is used
    
    ## Mean Squared Error
        * MSE = MAE = (1/n) sum(i=1 to n) (yi - yihat)^2
        * Advantages: Used as loss function because it is diffential at 0
        * Disavantages
            1. Unit of MSE is the sqare of unit of y and hence difficult to interpret
            2. It is senstitive to outliers. Not robust to outliers

    ## Root Mean Squared Error
        * RMSE = sqrt(MSE)
        * Advantages: Unit of output and y are same
        * Disavantages : Not robust to outliers

    ## R2 Score - Tells how well the model is performing
        * Independent of Context
        * Worst option for predicting is just providing the mean of y axis
            Eg: irrespective of the x axis: cgpa, predict y=y_mean
        * Best option is to do LR
        * R2 score: how much the LR line is good compared to the mean line

        * Also called as co-efficient of determination or goodness of fit 

        * Formula:
            R2Score = 1 - (SSr - SSm),
                where,  SSr is the sum of squared error in regression line
                        SSm is the sum of squared error in the mean line

        * Interpretation:
            --> R2Score = 0 means, SSr == SSm : Bad model
            --> R2Score = 1 means, SSr/SSm = 0 : possible when SSr = 0, means there is no mistake of regression line : Best model  

            * Best Model when R2Score is towards 1

            --> R2Score < 0 i.e negative, SSr/SSm > 1, means: SSr > SSm
                * Regression line is worst than the mean line 

            --> If R2Score = 0.80 for the data of cgpa and package
                * means cgpa is able to explain 80 percent of the variance of the package
                * i.e input is able to explain 80 percent of the variance of the output

        * Disavantages:
            1. Adding more features, increases the R2Score or will remain the same, even if the features added are irrelevant

            * This is handled by Adjusted R2Score

    ## Adjusted R2 Score 
        * Formula

            A_R2Score = 1 - [[(1-R2Score)(n-1)]/(n-1-k)]
                where,  n is the number of rows (total data points)
                        k is the total number of independent rows 

        * Helps in multiple LR problem
